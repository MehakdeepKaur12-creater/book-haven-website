# Book Haven

Book Haven is a frontend-only bookstore website built using HTML and CSS. It is a static website with multiple linked pages designed to showcase books, categories, and a simple user-friendly browsing experience.

## Features

- Multiple static HTML pages
- Clean and responsive layout
- Custom CSS styling
- Book categories and display sections
- Image assets for visual design
- Simple navigation between pages

## Technologies Used

- HTML
- CSS

## Project Type

Frontend Static Website

## Note

This project does not include JavaScript functionality or backend/database integration. It focuses on frontend structure and design only.
